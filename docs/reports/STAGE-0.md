- 调试面板：只读 `GameManager` 真实状态

## 有趣性自评（阶段 0 无玩法，不做“有趣”判断）

**最可能让游戏不好玩的风险假设：**

如果 Shift 只是“换一个角色继续按键”，而不是“另一个角色正在失控、需要被救回来”，玩家不会感到双角色依赖。那样它就是一个普通的双角色切换游戏，GDD 的共享意识卖点不成立。

**阶段 1 怎么验证：**

只做兔子 + 乌龟 + Shift + 滑落/下沉 + 上浮接人，录一段 60 秒连续操作，检查是否出现计划性操作（先让兔子跳，再切乌龟下潜，再上浮接人），而不是一直按同一个角色。若始终不需要切换就能前进，核心玩法不成立，停下来汇报。
