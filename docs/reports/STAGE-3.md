## 已知问题

1. **Showtime 结束时控制权回到演出前的一方**。自动驾驶在表演中下潜时，表演一结束乌龟失去操作会继续下沉（首次出现在 x≈6136，事故 2.0 s）。这是 GDD 规则不是 bug；测试改为每帧确认还在操作乌龟（`_ensure_turtle`）。真人可能觉得操作被“抢走”，阶段 5 要观察。
2. **熟练玩家门槛可能偏低**：脚本零事故、54/54、296.6 s，S 阈值 10000 在“零事故 + 全连击”下稳达。需要真人数据再校准。
3. **自检污染个人纪录**：阶段 0/1 自检用瞬移到终点验证结算，`finalize_run()` 把 0.02 s 写成最佳时间；已改为备份/还原 `user://best.json`，并恢复了被覆盖的真实纪录。玩家可见逻辑不受影响。
4. **Zone 1 中段太空**（见下）。

## 有趣性自评

1. **新增操作能否一句话说清用途？** 阶段 3 没有新增按键：仍是「SHIFT 换人、上跳/上浮、下趴/下潜、右加速」，三个区域只是同一套动作的组合。能。
2. **有没有一次“我做了判断，然后成功了”的瞬间？** 有。看到 LOW BEAM 选择下潜而不是跳，连续 3 次干净通过触发 SHOWTIME；本局 54/54 干净通过、18 次 Showtime、Perfect Streak 54。证据：`stage3-run.log` 的 CLEAN PASS / show 计数。
3. **操作错了有没有可见后果？** 有。修复前的运行在 5300 与 38200 的岩石处出现 RABBIT_STUN：硬直 0.8 s、连击清零、事故 +1、评分 −250；阶段 2 回归还记录了 RABBIT_SLIP 与 TURTLE_REEF。证据：`stage3-run.log` 的 ACCIDENT 行（t=24.3、t=182.8）。
4. **比上一阶段多了一个想再试一次的理由吗？** 有。结算给 S–D 等级、总分和四项个人纪录，R 直接重开；本次把最佳时间从 305.1 s 打到 296.6 s，结算显示 NEW BEST TIME!。证据：`stage3_result.png`、`stage3_menu.png`。

**本阶段最无聊的 30 秒**：Zone 1，x≈7,600–12,500（t≈36–61）。25 秒里只经过 2 组障碍（9,000、11,000），高度一直是水面 300，玩家只需按住前进。原因是教学段之后的 2,000 px 空档。建议把 7,000–12,500 中段间距压到约 1,400 px，或插入加速带。

**结论：有保留。** 组合与 Showtime 的节奏成立，但 Zone 1 中段空、脚本零事故说明熟练玩家门槛偏低；需要真人试玩确认后再判“有趣”。
