## 一句话

鲨鱼从“钉在水面的静止障碍”改成“靠近才醒的水下伏击”：平时整条鱼沉在
528～720（乌龟任何可达深度都碰不到）→ 进入 0.95 s 航程后先亮 0.55 s
预警（水面鳍、泡泡、“!”）→ 0.12 s 冲上水面压 1.4 s（只能跃起）→
退 0.55 s 回深水。退避一开始壳就失去支撑、自动放行，P0 的“静止鲨鱼把壳
无限顶住”从机制上消失，而不是靠加冷却或放宽碰撞。

唤醒距离按“时间”给，所以三个区（220/240/260 px/s）都是“壳碰到鱼正好在
预警后 0.95 s”，玩家学一次就通用；不是按固定像素，也不是全局计时器。

## 几何：为什么窗口是这个位置

- 内缩壳底 359，上冲鲨顶 288 → 跃起要抬 71 px；1.6 s 正弦跃起里
  `sin > 71/160 = 0.444` 的时间段是 **0.235～1.365 s**（1.13 s）。
- 壳与鱼的重叠横向距离 70+90=160 px → 以 220/240/260 px/s 穿过要
  **0.73/0.67/0.62 s**。
- 壳接触鱼在预警后 0.95 s，离开在 1.68/1.62/1.57 s。
  起跳太早会在“离开时”已经落回鱼顶以下，太晚则在“接触时”还没抬起来。
  于是安全窗 = [离开−1.365, 接触−0.235] → Z1 0.31～0.72、Z2 0.25～0.72、
  Z3 0.20～0.72，共用段 **0.31～0.72 s**；探针实测因帧量化/加速为
  0.15～0.65、0.20～0.65、0.25～0.65、0.30～0.65。

## 过程中修掉的两个真 bug

1. **抽取把 gate3 换成 SHARK，却没有伏击运动**。`apply_snack_draws` 用
   `build_group` 重建组，而 `build_group` 只从 spec 读 `motion`，默认种子
   把 gate3 抽成 SHARK 后得到的是一条**静止在水面的鲨鱼**——P0 的钉子
   换了个入口回来了。修法：抽成 SHARK 时补 `motion`；并把 `_init_ambush()`
   挪到抽取之后（先建状态会漏掉被抽成鲨鱼的那组）。探针现在对“装载后
   每一种 SHARK”都断言有伏击状态。
2. **坐标写错会静默偷袭**。旧注释用未位移的 254 算潜伏框；实际运行时是
   288～480。若按 254 取 240 的位移，潜伏框顶 494 会切进最深壳底 512。
   现在常量取 240（528 顶，距 512 有 16 px），注释统一写运行时坐标；
   探针在 0/50/100/150 四档深度实测最小余量 **19 px**、0 次相交。

## 三条未过（需要制作人裁决）

### 标准 2：“全部撞上，0 次事故”

两句互斥。本游戏的“撞上”就是一次失误：`_check_hazards → _turtle_contact →
note_mistake`，`accident_count + 1`、BRO METER + 1、扣 100。实测每次巡航组
都是 `hit=true / hit_roles=turtle / daze=3.6 / accident_count=1`，**这一撞就是
那 1 笔**，没有第二种事故。要按意图判，标准应改成“每次撞上恰好 1 笔事故，
且这 1 笔就是上冲碰撞；无额外事故”。本轮没有为了让数字变 0 而绕过记账。

### 标准 3：“预警后 0.3–0.9 s 起跳全部通过”

按字面不可能，任何参数都做不到：

- 跃起高于鲨顶的窗口 **1.13 s**（`LEAP_TIME=1.6`、`LEAP_HEIGHT=160` 固定，
  且这两个数还被岩/墙复用，本轮不许动）。
- 壳与鱼的重叠至少 `(70+90)/260 = 0.62 s`（最快区）。
- 安全窗口宽 ≤ **1.13−0.62 = 0.51 s**，而 0.3 与 0.9 相距 0.6 s > 0.51 s。
  所以“0.3 和 0.9 同时过”在几何上无解，与参数怎么调无关。
- 实测窗口（0.05 s 档扫）：Z1 0.30–0.65、Z2 0.25–0.65、Z3 0.20–0.65。
  0.3、0.6 都过；0.9 必撞（接触在 0.95 s）。

可选裁决：
1. 接受实测窗口，把标准 3 改成“0.3–0.6 s 起跳全部通过 + 窗口 ≥0.3 s”；
2. 把预警提前到 1.2 s（接触 1.2 s，窗口 0.56–0.96），这样 0.9 能过、
   0.3 过不了——仍然是 0.4 s 宽；
3. 改跃起参数/缩鲨鱼（会动到岩墙的既有窗口，不建议）。

### 标准 1：“正式赛道 6 组鲨鱼都循环”

六组**定义**都实现了、也都循环了；但默认种子的 Phase P 抽取会把

2. 让抽取不替换原本是 SHARK 的组（会破坏 Phase P 的“同区不重复/池内”验收，
   且让 Z3 失去两种障碍的随机性）；
3. 换默认种子（会改整条赛道的障碍组合，之前的证据链全部要重跑）。
