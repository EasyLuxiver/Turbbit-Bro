# Z1 室外码头美术试验

- 素材：制作人提供的室外码头图（1920×1080）。
- 范围：只做 Z1 背景与水面表现；不改碰撞、关卡、角色或机制。
- 未导出、未部署；`best.json` 未变。

## 做法

1. **抠图**：把水线以下的平蓝水面按颜色距离抠成透明，保留码头、房子、船、木桩；
   生成 `assets/art/z1_dock_cutout.png`。
2. **倒影**：取水线附近 130 px 的码头带，垂直翻转，作为水下倒影。
3. **Z1 背景**：按世界坐标 1600 px 平铺，正常/镜像交替，只铺到 Z1 结束 10000；
   原有 Z1 的平色背景、岛、棕榈、浪层全部隐藏。
4. **玩法水柱**：
   - 不透明上青下深的水体，盖住原图平蓝；
   - 水面泡沫线、焦散、斜向光柱、上升气泡、水面高光；
   - 码头倒影压在水面下。
5. 截图探针：`scenes/stage51_z1_art_capture.tscn`。
