# 轻压力 + 搞笑小动作 + Q 弹碰撞规划书

> **状态：待制作人审阅。审阅通过前不改玩法代码。**
> 背景：兔子和乌龟吃了大表哥的电击蛋糕，一个意识、两个身体；切人就是电一下。
> “梦游”只是比喻——不是持续干扰、不是第二套 AI、不是惩罚计时器。

## 1. 目标

1. **持续压力很轻**：玩家能感觉到“另一个身体在走神”，但不会烦、不会被抢控制。
2. **乐趣来自表演**：美术和预设的搞笑小动作，不是又一套惩罚。
3. **乌龟撞击 Q 弹**：把现在的“瞬移后退”改成压扁→弹开→过冲→回弹的卡通物理。
4. 不新增按键、不新增敌人/障碍种类、不改下潜规则、不引入新美术素材。

## 2. 现状（代码事实）

- **乌龟弹回**：`_apply_bounce()` 目前在乌龟层障碍撞上后直接 `x -= 140 px`，
  速度归零 0.8 s 冷却；同组后续不重复扣分，连续 6 次 `BONK_OUT`。
  `stage45_bounce_recovery` PASS。问题：位移是瞬移感，不是碰撞感。
- **旧的 MISCHIEF**：失误后 7 s 抱怨窗口、1.2 s 反应、0.65 s 预兆，
  然后拽绳/电击。它是“失误驱动的惩罚事件”，不是连续压力。
- **HUD**：每个角色有小头像；没有旧的 0/3 面板。
- 鲨鱼看台已暂时移除；`stage21` 断言 `no_stands` PASS。

## 3. 新机制：走神条（轻压力）

### 3.1 规则

- **每个身体一条独立的“走神”条**，只在没被控制时增长；
- **没满之前完全不干扰**：不改速度、不改碰撞、不改氧气、不抢输入；
- 切换到这个身体 = 把它“电醒”，条下降；干净通过也压一点；
- 条满时触发一次**搞笑小动作**，有 0.65 s 预兆；预兆期间切回该身体可取消；
- 后果是**轻的**：掉一点连击/分数，或 0.5 s 小减速；不记事故、不扣氧、不打断控制；
- **部分动作是正收益**（例如偷吃海藻给一点氧/分），让玩家可以把它当玩具，
  而不是单纯躲它。

### 3.2 阶段

| 阶段 | 条 | 表现 | 是否影响玩法 |
|---|---|---|---|
| 清醒 | 0–40% | 正常 | 否 |
| 走神 | 40–70% | 打哈欠、发呆、Zzz 气泡 | 否 |
| 耍宝前 | 70–95% | 伸懒腰、叉腰、跟海鸥挥手、偷看零食 | 否 |
| 耍宝 | 95–100% | 0.65 s 预兆 → 一个搞笑动作 | 只掉连击/分或小减速 |

### 3.3 动作池（预设）

| 动作 | 触发 | 表现 | 后果 |
|---|---|---|---|
| 打哈欠/伸懒腰 | 低阶段 | 张嘴、拉长身体、Zzz | 无 |
| 跟海鸥挥手 | 海鸟附近 | 抬手挥两下 | 无，纯喜剧 |
| 叉腰得意 | 刚干净通过 | 挺胸、抖两下 | 无 |
| 偷吃海藻 | 附近有食物 | 伸手抓一口 | **+少量氧/分**，可故意留 |
| 发呆半步 | 中阶段 | 慢慢挪半步 | 位置轻微偏移，不碰撞 |
| 说梦话 | 随机 | 气泡一句台词 | 无 |
| 缩壳/抱膝 | 高阶段 | 缩起来 | 0.5 s 小减速 |
| 惊醒抽动 | 满条 | 电弧一闪、身体一抖 | 掉连击/分，不记事故 |

原则：**动作是表演，不是攻击**；不做“拽绳/电击对方”这种恶意动作。

### 3.4 和旧 MISCHIEF 的关系

建议：**用走神条替换旧 MISCHIEF 的“抱怨→拽绳/电击”**。
原因：两套“没被控制的角色自己动”的系统会重叠，玩家会分不清是惩罚还是表演；
旧的抱怨/拽绳已经是失误驱动的惩罚，不符合“轻压力 + 搞笑”的方向。

保留：事故、氧气、救援、鲨群；只替换 MISCHIEF 的触发和动作池。
**这条需要制作人确认。**

## 4. Q 弹碰撞

### 4.1 一套动作

1. **接触**：壳压扁（横向 1.25、纵向 0.75），兔子前倾、耳朵滞后；
2. **弹开**：ease-out-back，后退 160–200 px，0.35–0.45 s；
3. **过冲**：退过头 10–15%，再被拉回；
4. **回弹**：壳 scale 2–3 次阻尼摆动（1.25/0.75 → 0.9/1.1 → 1.0）；
5. **余震**：镜头 2–3 px 抖、水面涟漪、两条橡皮筋弧线、`BOING!` 字；
6. **连续撞**：囧脸和晃动逐级加大，第 6 次仍 `BONK_OUT`。

### 4.2 实现

- 碰撞判定不变；位置用弹簧/阻尼，不直接 `x -= 140`；
- 画法层单独做 squash/stretch 和阻尼摆动，不碰碰撞体；
- 建议先做**视觉弹簧**：位置仍由现有逻辑决定，画法加 offset/scale；
  如果看起来还不够，再把位置改成真实弹簧；
- 不做真实物理，做卡通物理：过冲、回弹、余震比精确碰撞重要。

### 4.3 可调参数（制作人后续调试）

| 参数 | 默认 | 轻 | 夸张 |
|---|---:|---:|---:|
| 后退距离 | 180 px | 140 px | 220 px |
| 弹开时长 | 0.40 s | 0.50 s | 0.32 s |
| 过冲 | 12% | 8% | 18% |
| 压扁 | 1.25 / 0.75 | 1.15 / 0.85 | 1.35 / 0.65 |
| 回弹次数 | 3 | 2 | 4 |
| 镜头抖动 | 2.5 px | 1.5 px | 4 px |

默认 1.0；制作人试看后可整体乘 0.7（轻）或 1.3（夸张）。

### 验收标准（先写 qc.py）

1. 走神条只在未控制时增长；满之前速度/氧气/碰撞/输入不变（stage53）；
2. 满条有 0.65 s 预兆，切回该身体可取消；后果只掉连击/分或 ≤0.5 s 减速（stage53）；
3. 至少 2 个动作是正收益/纯喜剧，玩家可主动留着看（stage53 + 截图）；
4. Q 弹无瞬移：接触压扁、后退 160–200 px/0.35–0.45 s、2–3 次回弹（stage45）；
5. 连续 6 次 `BONK_OUT` 仍成立（stage45）；
6. 全关 53/53、无卡死、`best.json` 不变（stage3_playtest）。

## 6. 顺序与风险

1. 先做 Q 弹（视觉层，风险最低，`stage45` 可量化）；
2. 再做走神条单段原型（Z2 3000 px，测试里关旧 MISCHIEF）；
3. 制作人看截图/录屏调“轻/夸张”；
4. 最后才接全关。

风险：

- 走神条太快 → 玩家烦；太慢 → 没感觉。默认 12–15 s 填满，Z3 10–12 s；
- 动作池太多 → 抢戏；先做 4 个（哈欠、偷吃、发呆半步、缩壳），其余后加；
- Q 弹太强 → 晕/挡视线；默认 1.0，制作人可乘 0.7；
- 两套压力系统重叠 → 建议替换旧 MISCHIEF，不并行；
- 没有真人试玩 → 先给截图/录屏和探针数据，不冒充手感结论。
