## 1. 本轮结论

FEEL-40 没有继续压 Z3，而是把“第一次提前换人”和“第一次有代价的选择”
放到 Z1/Z2：

| 位置 | 之前 | 现在 |
|---|---|---|
| Z1 首个换人 | log1 的 BRO DIVE 才有明确双人操作 | gate1→rock2 在 **16 s** 就有“拱下潜→换兔子跳”的连招提示 |
| Z1 选择 | 无 | bird2 双解：兔子趴低（免费）/ 乌龟继续下潜（耗氧，省一次换人） |
| Z2 提前换人 | gate4 前 4.4 s 才看到 | rock6→gate4 **2.93 s**，提示“提前换人” |
| Z2 决策 | rock6 双解未形成下一步收益 | 乌龟潜过 rock6 可直接接 gate4；兔子跳则必须立刻换乌龟 |
| Z3 五组紧接力 | 2.0–2.5 s | **原样保留**，间隔没有继续缩短 |

## 5. 随机抽取语义

FEEL-37 修了 `combo/relay/dual` 被抽取覆盖的问题；FEEL-40 又发现两个问题：

1. 结构性组本身仍可能被换角色：
   - `shark9` 被抽成 `LOW_BEAM` 后，`bird8` 的“鲨鱼退→换兔子”消失；
   - `log7` 被抽成 `SHARK` 后，`rock10` 前的 BRO DIVE 语义变化。
2. 结构性组的**前一拍**也会被抽走，导致连招两端的角色关系失效。

修法：

- 组本身是 `relay` / `dual` / 有 `combo`：不参与随机种类替换；
- 下一组是结构性组：这一组也不替换；
- `apply_snack_draws` 继续保留 `combo/relay/dual`，并为双解/接力岩石保留可下潜答案。

结果：当前种子下 `log7` 保持 FLOATING_LOG，`shark9` 保持 SHARK；
食物抽取仍会改变非结构组（如 beam1、bird3、bird5、rock11、rock12），
但不会再拆掉连招。
