## 1. 先认两个坐标债

### 1.1 码头没了 / 山树靠近消失

Phase 5 压缩后，Z2 从 `15000–39000` 改成 `10000–34000`，但三处仍用旧坐标：

| 文件 | 旧值 | 应改为 |
|---|---|---|
| `scripts/world/zone2_dock.gd` | `ZONE_START 15000 / ZONE_END 39000` | `10000 / 34000` |
| `scripts/world/zone2_layer.gd` | `ZONE_START 15000 / ZONE_END 39000` | `10000 / 34000` |
| `race.gd::_draw_zone2_blend` | `x0=14600 / x1=15200` | `9600 / 10200` |

后果：Z2 前 5000 px 没有码头；码头到 15000 才出现、到 39000 才退场；Z1 的山/树在 10000 被硬裁剪直接消失。这是视觉 bug，不是美术问题。

**修法：**

- 三处常量改成新坐标；
- `_draw_zone1_layers` / `_draw_zone3_layers` 不要用 `return` 硬裁剪，改成在区域边界前 600 px 把整层 alpha 淡到 0；
- 每个颜色乘 `Color(1, 1, 1, fade)`，不引入新节点；
- 更新 `p0d_entry` 里写死的 15000 边界检查到 10000；
- 截图验证：Z1→Z2 入口（9600/10000/10400）和 Z2→Z3 入口（33400/34000/34600）没有硬切、没有空洞。

### 1.2 海鸟飞出屏幕还在攻击

鸟进入 ACTION/RECOVER 后，即使 `d < -260` 也不会停；排泄物还有 1.25 s 飞行时间；`_check_bird_attacks` 只在救援时清空，不按镜头位置清。码头前半段正是鸟组刚被超过、投射物还在飞的位置。

**修法：**

- `_tick_bird_behaviors`：当鸟组在镜头左侧超过 `0.5 × 屏宽` 时，整组置 `DONE`，清掉该组 `_bird_attacks`；
- `_spawn_bird_attack`：只允许鸟在屏内或前方时发射；
- `_check_bird_attacks`：投射物所属组已在镜头后方 `0.6 × 屏宽` 时直接移除；
- `stage19_bird_behavior` 增加 `bird_off_screen_no_attack`。

## 2. 表现补充

### 2.1 便便：螺旋、旋转、落水停转下沉

现在是一个不规则棕色团块，飞向兔子身体高度，命中或落地后直接消失。

改成：

- 目标点 `p1` 改到水面：`y = SURFACE_Y + 10`，不再瞄兔子身体；
- 飞行中画**螺旋/卷曲**（懒羊羊发型那种卷）：24 个点，`ang = spin + i * 0.55`，`r = 2 + i * 0.45`，`draw_polyline`；`spin` 随 `t` 旋转；
- 落水后加入 `_poop_sinks`：停止旋转，`y` 在 0.6 s 内下沉 24 px，alpha 淡出；
- 落水时保留现有溅射圈和棕色水滴；
- **伤害只在落水溅射时判**（默认），飞行中不直接砸人；如果你要保留空中直击，再加一个很小的飞行判定。

### 2.2 教学 → 正赛：0.5 秒空挡，不要抽帧硬切

现在 `_finish()` 让大表哥说完 1.4 s，然后直接 `GameManager.start_race()`，场景硬切。

改成：

- 1.4 s 台词结束后，黑场 0.35 s；
- `start_race()`；
- 正赛开场黑场淡出 0.35 s；
- 用 `GameManager.race_fade_in` 标记只在“教学→正赛”时淡入，菜单/重试不强制；
- 不加新素材，只用 `ColorRect` + `Tween`。

### 2.3 鲨鱼群专场：攻击期间不出现普通障碍

从 `LEAD_LUNGE` 到 `RETREAT`（不含 `CIRCLE` / `DONE`），`shark6` 前后 1500 px 内的普通障碍：

- 不绘制；
- 不参与碰撞；
- 不进入 `next_hazard_info`（避免换人奖励/提示锁到隐藏障碍）；
- 不弹教学。

实现：`_shark_arena_active()` + `_shark_arena_hides(group)`，在上述四条路径统一跳过。`DONE` 后恢复正常；如果玩家已经跑过被隐藏的组，它就留在身后，不会突然冒出来。

### 2.4 狙击镜准星

在 WARN → HOLD 期间，套在被瞄准的角色身上：

```
              │
          ╭───┼───╮
          │   │   │
      ────┤   ●   ├────
          │   │   │
          ╰───┼───╯
              │
```

- 外圈直径约 70 px；
- 上下左右四根短杠，从圆环指向圆心，中心留约 12 px 空隙；
- 中心一个小圆点；
- WARN 琥珀、HOLD 转红；WARN 时圆环从 1.25× 收到 1.0×，HOLD 再缩到 0.92× 并闪一下；
- 准星跟随目标，不钉在鲨鱼身上；从鲨鱼到准星保留一条很淡的线；
- 下方小字 `TUBO` / `BITT`；
- `RETREAT` 淡出；
- 只用 `draw_arc` / `draw_line` / `draw_circle`，不引入素材。

### 2.5 乌龟也要有“快失控”的感叹号

乌龟现在有神游标记，但位置偏低、字号偏小，容易被壳/鲨鱼挡住。改成和兔子同款：

- 位置抬到壳上方约 96 px；
- 气泡和 `!` / `!?` 尺寸与兔子一致；
- `RESTLESS` / `MISCHIEF` 都显示；
- 仍只影响画法，不改变判定。

### 2.6 Showtime：从“大表演”改成“小奖励”

现在的 `start_showtime()` 原本是 1.8 s 自动表演；FEEL-24 之后正式流程没有触发点。按制作人的定位改成“小奖励”：

- **短**：0.7 s；
- **动作**：兔子小跳 + 一圈后空翻；乌龟滑板式 ollie，小幅度腾空 + 转一下；
- **不改变判定**：乌龟的腾空和旋转只在画法层，位置/碰撞不变；兔子 `rabbit.state` 短暂进入 SHOWTIME，但 900 px 内无障碍才触发，不会卡掉眼前的操作；
- **清空惩罚条**：`_clear_penalty_state()` 清 BRO 槽、抱怨/捣乱状态和头顶压力；
- **奖励小**：+100 分，氧气 +0.5，保留大字 **SHOWTIME**；
- **触发**：概率 15%，只在精准动作（BRO DIVE / BRO OLLIE / 干净接力）后判定；18 秒冷却、一局最多 3 次；不恢复 0/3 计数器；
- BRO DIVE / BRO OLLIE 计入 Showtime 触发池和统计，但反馈名仍保留。

验收：时长 ≤0.75 s、控制权不变、兔子/乌龟腾空 ≤30/24 px、惩罚条清零。

测试：`stage46_showtime_small.gd`——断言时长、控制权、腾空幅度、惩罚条清零。

### 2.7 鲨群攻击流畅度

- RISE 0.12 → 0.26 s，HOLD 0.55 → 0.60 s，RETREAT 0.45 → 0.55 s；
- 上冲加 12 px 过冲再回落；鱼身朝目标倾；
- 破水瞬间加水面弧/气泡/尾迹，退回留水线；
- 三只鱼队形用 0.08 s 阻尼跟随，不再硬贴；
- 准星从 WARN 保持到 HOLD，目标 `TUBO`/`BITT`；
- 同一时间只允许一只鱼 RISE/HOLD。

测试：`stage32_shark_timing` 仍 PASS；`stage21_shark_pack` 仍 PASS；新增 `stage49_arena_exclusive` 验证专场屏蔽。

## 3. 撞上障碍：乌龟被弹回，而不是卡死

这个方案比“原地提示 + 瞬移”更像游戏，也更符合乌龟的笨重感：

- 兔子乌龟一起撞上 → **受伤的是乌龟**；
- 乌龟被弹回 → 镜头跟着退一点 → 再自动前进；
- 玩家还是不动 → 乌龟再撞、再弹；
- 玩家看懂了、按对键 → 正常通过。

它不是新的敌人/系统，只是把“撞墙”从硬停改成一次可见、可重复的物理反馈。

### 3.1 适用范围

- 乌龟层障碍：`DIVE_GATE`、`HIGH_WALL`、`FLOATING_LOG` 下段、普通伏击 `SHARK`；
- 兔子层障碍（`LOW_BEAM` / `LOW_BIRD` / `SURFACE_ROCK`）仍是兔子被撞、乌龟继续走，不触发弹回；
- 鲨群三拍（`shark6` 专场）不弹回，避免打断三拍；那段用第 3.5 节的兜底。

### 3.2 弹回节奏

- 撞击瞬间：乌龟 `x` 后退 **140 px**；如果会退到上一组里，则停在“上一组末端 + 80 px”；
- 乌龟速度归零 **0.25 s**，再用 **0.35 s** 回到 base；
- 镜头正常跟随，不加长 hitstop；只加 2–3 px 镜头抖和壳的晃动；
- 兔子留在壳上，不额外受伤、不被甩出去；
- **第一次撞同一组**：走现有事故/扣分/抱怨；
- **同一组后续弹回**：只播弹回和“咚”，不再重复扣分/扣氧/记事故，避免呆呆玩家被数值直接打死；
- 玩家通过该组后，弹回计数和“已扣过分”状态清零。

### 3.3 连续六次 → 直接失败

- 同一组第 **2** 次弹回：由另一个兄弟说一句 `别硬顶！先换人！`（HUD 显示说话者小头像）；
- **连续撞 6 次**（期间没有干净通过）：直接 `BONK_OUT` 失败，不再瞬移兜底；
- 失败页写：**“我让我的兄弟晕过去了。”**，配兔子小头像；
- 干净通过任意一组，连续撞击数清零；
- 第 6 次之前仍可继续试，不会无限卡死；失败本身就是出口。

### 3.4 视觉

- 撞击点画一个短促的“咚”星形/冲击弧；
- 乌龟壳左右晃两下，兔子在壳上被带着前倾；
- 乌龟 1–6 级“囧”表情逐级变惨：眼睛从点变成 X、嘴从波浪变成下垂、第 4 级起头顶冒“囧”；
- 弹回时镜头轻微后退（跟随乌龟，不额外做镜头动画）；
- 不引入素材，纯几何。

### 3.5 测试

新增 `stage45_bounce_recovery.gd`：

- 合成一组 `DIVE_GATE`，玩家不输入：断言第一次撞击后乌龟 `x` 后退约 140 px、速度在 0.6 s 内回到 base；
- 连续撞同一组：断言第二次起不再增加事故数/扣分/扣氧；
- 第 2 次弹回出现提示，连续第 6 次弹回触发 `BONK_OUT`；
- 正常通过该组不触发弹回；
- 救援/暂停/鲨群专场不触发。

## 7. 风险与回滚

| 风险 | 处理 |
|---|---|
| 改码头坐标影响旧截图/探针 | 同步改 `p0d_entry` 的 15000 → 10000；重拍入口截图 |
| 便便改成落水判伤变简单 | 溅射半径先保持 30；stage19 命中用例必须仍过 |
| 弹回循环变成烦人 | 撞击只扣第一次；后续只播弹回；第 2 次给提示、第 6 次兜底；弹回全程 ≤1.2 s |
| 弹回把乌龟推进上一组 | 下限为“上一组末端 + 80 px”；没有上一组就停在组起点 - 200 px |
| 鲨群专场屏蔽到不该屏蔽的组 | 只屏蔽 `shark6 ± 1500` 且非 `shark6` 的组；`DONE` 立即恢复 |
| 文本改写扩大范围 | 只改叙事层；提示层保留按键名；先给清单 |
| 没有真人试玩 | 每项留截图/探针；最终标“工程验证”，不冒充真人结论 |
