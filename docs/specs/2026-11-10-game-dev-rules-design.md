# 游戏开发规则与阶段 0 设计

日期：2026-11-10
状态：制作人已批准（方案 A）

## 决定

- 新项目在 `TURBBIT/`，开发规则写在 `TURBBIT/CLAUDE.md`；根 `CLAUDE.md` 只加三条路由，不复制游戏规则。
- 阶段 1、5 停下来由制作人试玩确认；阶段 0、2、3、4 自评 + 记录后自动推进。
- 阶段验收复用 `LESSONS/CHECKS/qc.py`，不新建门禁脚本；`preflight.py` 是 GLB 专用，不用于游戏。
- 每阶段末固定四问 + “最无聊的 30 秒”，结论只能是 `有趣 / 有保留 / 不有趣`。
- 规则只做路由和门槛，任务书细节不搬进 CLAUDE.md，避免报告体系膨胀。

## 阶段 0 范围

Godot 4.7 工程，1600×900，`canvas_items`：

- 主菜单、比赛占位场景、结算占位场景
- `GameManager` 自动加载：游戏状态、控制角色、计时、氧气、速度、事故状态
- 输入映射：Shift / 右 / 上 / 下 / Esc / R / Enter
- 调试面板：显示真实运行状态
- 比赛占位：乌龟自动前进、上下移动、加速、Shift 切换、兔子滑落、氧气变化、到达终点

不实现：正式玩法、美术、音频、关卡设计。
