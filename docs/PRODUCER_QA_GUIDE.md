## 1. 启动与进入比赛

### 编辑器

1. 打开 Godot 4.7：
   `D:\Godot_v4.7-stable_win64.exe --editor --path D:\GAMESTUDIO\TURBBIT`
2. 打开场景：`res://scenes/menu.tscn`
3. 按 **F5** 运行（控制台版本可用 `D:\Godot_v4.7-stable_win64_console.exe --path D:\GAMESTUDIO\TURBBIT`）。

### 从菜单到比赛

1. 主菜单选 **开始游戏** → Enter。
2. 连环画：Enter 下一格；**ESC 可直接跳过**。
3. 教学：按 **K** 跳过，进入正式比赛。
4. 右上角显示 `RACE n/55`；从 `0/55` 起步。
5. 操作：`SHIFT` 换人，`↑` 跳跃/跃起/蹬墙，`↓` 趴低/下潜；`SPACE` 用于救援追近。
6. 正赛底部只保留简短的好接/救援/事故事件；教学句不再常驻。

不要在 QA 过程中改项目设置、关卡数据或 `best.json`。

## 3. SHARK6 三拍

### 实际动作

鲨群现在不是“水里三条鱼 + 另外凭空生成攻击体”。三只鲨鱼一直是同三只实体：
平时在船底跟随；轮到谁，谁就从深水**自己上冲**到攻击位置，压住目标后再退回深水。

1. **Leader（老大）**
   - 目标：乌龟。
   - 看到“老大要冲了……”后 **SHIFT 乌龟**，准备但不立刻跳。
   - 看到“**现在——跃起！**”再按 `↑`；这是预警后约 **0.35 s**。
   - 老大从水下升到龟壳高度，乌龟要用跃起让开。
2. **Fat（胖小弟，第二拍）**
   - 目标：兔子。
   - 看到“身后有胖鲨……”/预警后，**SHIFT 兔子**，按住 `↓` 趴低。
   - 胖鲨从水下上冲后压到兔子高度；趴低从它下面过，站着会中。
3. **Thin（瘦小弟，第三拍）**
   - 目标：乌龟。
   - 看到“瘦鲨压顶……”/预警后，**SHIFT 乌龟**，按住 `↓` 下潜。
   - 瘦鲨从水下冲成一条纵向压顶身体；下潜让开，巡航或跃起会中。

鲨群只在玩家实际进入 Z3 后入场；入场时先有“鲨鱼群围上来了”，
三拍顺序固定 **Turtle → Rabbit → Turtle**。预警保持 0.95 / 0.95 / 1.05 s，
安全间隔 0.70 s；每拍只允许一个攻击帧。上冲过程本身不判伤，鱼到达最终
攻击位置（HOLD）时才开始用它的身体判定，所以“正在下潜/跃起时被上冲鱼穿过”
不会算一次命中。

**已移除：** 旧的“鲨鱼随机摧毁前方低梁/海鸟”介入。它会把原障碍变成
断木，却没有稳定的后续攻击，已从正式流程删除。

### 快速进入鲨群

测试场已从正式主菜单隐藏，普通试玩不再显示入口。需要隔离观察时，
由 QA/开发在 Godot 编辑器直接运行 `res://scenes/test_arena.tscn`；
在障碍类型选择 **SHARK6**，点 **生成**。

测试场是隔离环境，不写 `best.json`，也不代表正式赛程的节奏；
正式试玩请从主菜单开始比赛。

自动化证据：`scenes/stage42_shark_fairness.tscn` 与
`docs/reports/longrun/feel42-shark-fairness.json`。这是真实 Input/race.tscn
测试，但执行者是测试代理，不是真人。

## 4. rock3 潮汐岩的两条路线

位置：Z1 约 00:33，浮标身份、随浪上下 52 px / 3.6 s。

- **兔子路线**：看浪谷跳过；不耗氧，但需要时机。
- **乌龟路线**：SHIFT 乌龟，按住 `↓` 下潜；耗氧，但稳定。
- FEEL-42 8 相位实测：兔子 **7/8** 通过，乌龟 **8/8** 通过。
  兔子失败的那个相位就是“时机不对”，不是随机判定。
- 双解提示：`prompt.dual_tide_rock`（兔子视角）/
  `prompt.dual_tide_rock_on_turtle`（乌龟视角）。

不要在 QA 时把一次兔子失败直接记为 BUG；先记录当时的浪相位和起跳位置。

## 5. 动态浮标 / 吊箱反馈

观察点：Z1 rock3、Z2 rock4/rock5/rock7、Z3 rock8/rock9/rock10/rock11/rock12
等会上下移动的岩/货箱。

乌龟被动态物体碰到时，应同时看到：

1. 撞击命中/停顿（hitstop）；
2. 镜头震动；
3. 乌龟减速；
4. 乌龟壳 **可见下沉**（`start_dunk`）；
5. 文字反馈（当前是“乌龟撞上浮标/木箱”类）。

氧气气泡：兔子头顶三颗。满氧三颗绿；第三颗随剩余量淡出；剩两颗时
**两颗都黄**；只剩最后一颗时红。不是三颗同时换色，也不是一绿一黄。

海鸟：第一段俯冲穿过后继续飞到玩家左侧，盘旋；第二段只做排泄，
目标兔子，不是乌龟。排泄按飞行时间预测落点，落地有溅射圈；
没有水弹。若落点紧邻浮木/其他障碍，本次特殊排泄会跳过，避免叠拍。

**海鸟判定：** 只有鸟真正扎进攻击窗口（DIVE）时，固定判定带才伤人；
鸟已经飞到左侧、开始拉起或盘旋后，身体穿过旧判定带不再判伤。
排泄落地按兔子身体框与落点圆相交判定，不再用“兔子中心点距离”。

**角色压力：** 不再画“撞一次永久加一格”的三格小条。受击是一次短促的
感叹号/摇晃，约 2 秒内消失；只有短时间内连续挨打才会变大、变红。
只改画法，不改数值、碰撞或控制。

MISCHIEF：失误后被留在失控状态的角色会生气约 7 秒；1.2 秒后若前方安全，
会在 0.65 秒预兆后动手。预兆头顶会写“拽绳/电击”。切回该角色可当帧取消。
兔子拽绳会真实降低乌龟速度并拉深壳；电击会打断乌龟下潜/跃起并留下
0.35 秒不能再潜的麻痺窗口；兔子在空中会被乌龟电落。不是只换一行字。

**S 等级：** 现在 S 要求 **0 次失误** + 8000 分；1–2 次失误最高 A，
3–5 次最高 B。结算页会显示“下一目标：S 需要 0 次失误”。

设置：主菜单 → 设置，可切换语言与全屏；选择写入 `settings.json`，重启保持。
Z1/Z3 现在有远景/中景/近景三层灰盒纵深（云、岛、棕榈、礁柱、吊架、浪线）。

终点：Z3 结束后不再是黑屏。水平线后是一段沙滩，终点门后站着大表哥；
冲线时他会举手，按等级给不同台词。沙滩、终点门、遮阳伞都还是灰盒几何。

双解：目前共 10 组（bird2 / beam4 / beam5 / rock3 / rock6 / bird4 / bird5 /
bird6 / rock8 / rock10）。兔子路线更快但不耗氧，乌龟路线更稳但耗氧；
两组路线都已在 `stage35_combo_audit` 里实测通过。

乌龟朝向：救援/被顶回向左移动时，头会转向左，不再倒着后退。

乌龟 SPACE 救援：现在会同时追兔子的 x/y，按住 ↓ 也可以；接住后 carry
会把乌龟抬回巡航、把兔子放回壳，并在接住瞬间补氧，不再因为最后一口气
在抬升途中失败。

兔子落水后是独立个体：救援阶段的轻微吸附只拉横向，不再跟着乌龟上浮/下潜；
要接住仍必须把乌龟潜到兔子附近。

兔子食物：高跳保留到下一次兔子普通起跳才消耗（1.30×）；视觉箭头会一直提示到起跳。
乌龟食物：加速持续到下一个障碍后的一段距离，速度线可见。

高墙 vs 浮木：高墙是带水下基座的灰色石墙 + 墙齿，不再悬空，也没有世界文字；
浮木是棕色木段 + 水下亮边。看到灰色石墙不要尝试下潜，用 BRO OLLIE。

BRO DIVE：兔子跳 + 乌龟下潜完成后，水下骑乘兔不再因为与浮木水下段擦边
而卡在木前；BRO DIVE 的辅助下潜已在 SHIFT 后接管。浮木缩到 215 后，
单乌龟也能过，BRO DIVE 仍是更稳的解法。

不应发生：

- 升级成事故/扣格；
- 写入 `hit_roles`；
- 无反馈的静默命中。

自动化验证：`scenes/stage15_dynamic_buoy.tscn`；
`dunk_timer=1.80`，浮标和吊箱一致；静态岩不误伤。
证据：`docs/reports/longrun/core-feel-15-dynamic-buoy.json`。

## 7. QA 反馈模板

每次问题复制一条：

```text
[QA 编号]
发生位置：区域 / RACE n/55 / 组名（能认出的画面物）
当前角色：兔子 / 乌龟
输入动作：SHIFT / ↑ / ↓ / SPACE / 无
视觉预警：看到什么文字、什么动作、提前多久
实际结果：通过 / 命中 / 事故 / 卡住
重复性：一次 / 多次 / 必现
主观感受：看得懂吗？来得及吗？觉得公平吗？
截图/录屏：路径或文件名
备注：
```

建议至少覆盖：

- Z1 `gate1→rock2`、`rock3`、`bird2`；
- Z2 `rock6→gate4`、`shark5→bird5`；
- Z3 `shark6` 三拍；
- 五组紧接力；
- 动态浮标/吊箱。

## 9. 已知限制 / 请重点判断

1. 老大从水下上冲，乌龟的跃起窗口比旧版更依赖“看到现在——跃起再按”；
   请确认玩家能从鱼的上冲动作读出时机。
2. 三只鲨鱼攻击时都由同一只鱼从水下升到目标位置，不再从玩家身后滑入；
   请确认“鱼从下面来”的方向感是否清楚。
3. Z1 没有 <2.5 s 强制切换；Z2 的 `rock6→gate4` 是 2.93 s；请判断前两区是否够有趣。
4. 五组紧接力和 SHARK6 时序没有继续压缩；请先判断可读性，不要直接以难度调参。
5. 反馈仍是文字/姿态级，没有美术和音频。

## 10. 保护项

- 不修改代码、关卡数据、攻击参数、SHARK6 时序。
- 不修改 `best.json`；测试场和自动跑不应当作玩家纪录。
- 不导出、不打包、不复制 EXE；不覆盖公开 Web；不发布。
- 指南本身只做文档，不自动启动新的 FEEL 优化。
